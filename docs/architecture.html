DataPulse Architecture

Data contract and pipeline observability platform — v1.0.0

Core Platform

  • • FastAPI with 14 REST endpoints
  • • 5 quality checks (readability → freshness)
  • • Versioned data contracts
  • • Idempotent run submission
  • • Incident creation + ownership

Data Layer

  • • PostgreSQL 16 (8 tables, Alembic migrations)
  • • SQLite for local dev + unit tests
  • • DatasetReference abstraction (local/S3/table)
  • • Streaming CSV for large datasets
  • • Durable notification history

Observability

  • • Grafana dashboard (7 panels, 30s refresh)
  • • 4 alert rules → webhook delivery
  • • Operational metrics endpoint
  • • API key + webhook secret auth
  • • 92 tests, CI with 5 jobs
